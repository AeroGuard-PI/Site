# Documentação AeroGuard

Este diretório é o ponto de entrada para integrantes e agentes que vão criar ou integrar páginas.

1. Leia [`../AGENTS.md`](../AGENTS.md): regras obrigatórias de implementação, backend e segurança do schema.
2. Leia [`../DESIGN_SYSTEM.md`](../DESIGN_SYSTEM.md): índice do Design System e fonte dos tokens.
3. Consulte os documentos de [identidade](design-system/01-identidade-visual.md), [tipografia](design-system/02-tipografia.md), [layouts](design-system/03-layouts.md), [componentes](design-system/04-componentes.md), [iconografia](design-system/05-iconografia.md), [interações](design-system/06-interacoes.md) e [responsividade](design-system/07-responsividade.md).
4. Leia o [guia de criação de páginas](design-system/09-guia-criacao-paginas.md) e use o [template de dashboard](templates/dashboard/README.md).
5. Antes de abrir revisão, execute o [checklist de integração](design-system/10-checklist-integracao.md).

Consulte [08-inconsistencias.md](design-system/08-inconsistencias.md) para pendências conhecidas. Novas páginas devem reutilizar tokens, classes e estruturas existentes; não devem criar uma identidade visual operacional nova sem autorização.
